# AimMod for osu! 0.2.1

- Choose 5, 10, 25, 50 or 100 active automatic practice sets in Settings > Practice. New settings default to 25; existing limits are preserved.
- Manually generated practice sets now import into the AimMod coaching collection even when automatic generation is off. Manual sets remain protected from automatic cleanup.
- Practice sections include up to three preceding notes, capped at 1.5 extra seconds at the selected speed. The short run-up repeats each round and stops at breaks or spinners.
- Lowering the active-set limit keeps existing sets and pauses new automatic sets until space becomes available.

The playable run-up applies to newly generated sets. In osu!stable, close the game once to allow a pending collection update.
