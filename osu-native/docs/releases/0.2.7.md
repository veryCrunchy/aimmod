# AimMod osu 0.2.7

## Training

- Choose drills from visual skill cards and presets, with clearer practice settings.
- Practise more varied reading patterns with controlled spacing, phrase breaks, sliders and optional spinners.
- Try reaction exercises with key choices, GO/STOP cues and adjustable response windows.
- Use the new spinner trainer to work on rotation speed, consistency, key holds and controlled movement. Spinner results are saved locally; profile sync for this trainer is not available yet.
- Enable guidance for cues during exercises, then practise with fewer prompts toward the end. Guided results remain separate from unguided comparisons.

## Navigation and performance

- Clearer home-screen illustrations and coaching practice choices.
- Smoother filter changes through background queries, debouncing and replacement of outdated work.
- Background PP cache loading and saving, with result rows added in small batches.
- Faster installed-map checks and fewer unnecessary list rebuilds when navigating or selecting results.
- Statistics filtering and history aggregation run outside the UI update thread.
