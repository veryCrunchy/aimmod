# AimMod for osu! 0.2.0

## Trainers

- Practise tapping accuracy, alternating, bursts, rhythm changes, aim control, reading and reaction.
- osu!standard drills run in the embedded game with the player's skin and supported input settings.
- Choose pattern types, note speeds, sliders, spacing and reading difficulty. Skill-based randomization limits generated patterns using recent practice and replay evidence.
- Practise with installed songs or original AimMod music, with ten arrangements, multiple tempos and a persistent shuffle option.
- Sessions finish with time for the final tap, an audio fade and a results screen.

## Coaching and map discovery

- Compact coaching pages organize practice sets, section history and original-map comparisons.
- Automatic practice settings manage generation, imports, collections and cleanup.
- PP targets use more play evidence and bounded parallel analysis to distinguish achievable targets from unsupported projections.
- A shared UI system brings consistent navigation, controls, search and popup layering across workspaces while retaining osu!-style range sliders.
- First-run setup introduces the app and its account, practice and sound settings.

## Training profiles

- Optional background sync keeps new completed training sessions on AimMod Hub, with persistent retries and account isolation.
- Sessions are private by default. Public sharing adds training history, skills, practice time and comparable-drill progress to profiles.
- Manage training visibility from Settings → Account & sharing → Training.
- Existing local history is not uploaded automatically.
