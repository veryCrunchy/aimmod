# AimMod 0.2.11

## Double Time practice

- Open Trainers > Mod trainers to work a map up from normal speed to full DT.
- Practise an installed difficulty with its original circles, sliders and spinners, using your osu! controls and skin.
- Two clean runs raise the speed a little. If accuracy or misses slip, the next attempt slows down.
- Track your current speed, clean runs and recent attempts separately for each map.

## Easier trainer navigation

- Skill trainers and Mod trainers now have separate tabs that preserve your selection.
- The DT map picker groups compact difficulty choices by song.
- A dedicated session panel keeps progress and the next Play action together. Smaller windows have a clear path between map selection and the session.

## Clearer practice-map titles

- Automatic and manual practice maps now include the source difficulty in the song title, for example: Song Name [Insane] - AimMod practice.
- The new naming applies when maps are generated or regenerated. Previously installed maps keep their existing titles.
