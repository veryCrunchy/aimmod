# AimMod 0.3.0

## New training music

- A rebuilt collection of 14 AimMod songs, each with versions at 90, 120, 150, 180 and 210 BPM.
- New melodies, arrangements and instruments, with the three-note AimMod signature woven into each song.
- Find the collection in Trainers, including Last Bus, Second Wind, Breakwater and Good Company.

## Practice that follows the song

- Generated sessions use the song's musical phrases, instrument attacks and held notes to place patterns and sliders.
- Pattern intensity follows changes in the arrangement, with room to recover in quieter sections.
- More varied movement, slider shapes and spinner placement for the trainers that support them.

## Adaptive sessions and difficulty targets

- Adaptive is the default: AimMod chooses the note rate, movement and object mix using your selected skill and recent performance.
- Manual mode keeps detailed control over your session settings.
- Set a target star range and AimMod checks the generated map with osu!'s difficulty calculator before starting. If the setup cannot reach your range, it explains what to adjust.
- Approach rate, circle size and timing difficulty adapt to the training mode and difficulty.
- Training history distinguishes difficulty targets so an easier session does not count as evidence for a harder goal.
